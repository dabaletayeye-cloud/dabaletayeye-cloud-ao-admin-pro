## 6. 路由新增流程

1. 在 `src/pages/` 下创建页面，并根据页面类别放入对应子目录。
2. 在 `src/App.tsx` 增加懒加载或静态导入及 `<Route>`。
3. 在 `src/components/Sidebar.tsx` 增加菜单项；横向导航需要同步修改 `HorizontalNav.tsx`。
4. 如果页面标题需要多语言，在 `src/hooks/useLocale.tsx` 补充导航键映射，并在语言资源中增加词条。
5. 运行 `npm.cmd run build`，确认路由、导入和类型检查无误。

## 7. 清理模块标记

可清理页面的导入、路由和菜单通常使用以下标记包围：

```tsx
/* CLEAN_DEMO_START: module:block */
// imports or routes
/* CLEAN_DEMO_END: module:block */
```

新增可清理模块时，必须同步更新 `scripts/clean-demo.config.json`，否则清理和恢复脚本无法正确处理依赖。

# 组件与演示内容清理命令说明

本文档说明 `ao-admin-pro` 项目中清理组件、演示页面和构建产物的命令。所有命令都应在项目根目录执行。

## 1. 执行前先预览

推荐先运行预览命令，预览只显示将删除和更新的内容，不会修改文件：

```powershell
npm.cmd run clean:core:dry
```

也可以预览压缩包/本地改动项目的清理范围：

```powershell
npm.cmd run clean:core:no-git:dry
```

## 2. 清理构建产物

只删除 Vite 生成的 `dist/` 目录，不会修改源码：

```powershell
# 预览
npm.cmd run clean:dist:dry

# 确认删除 dist/
npm.cmd run clean:dist
```

## 3. 核心版清理

核心版会保留登录、注册、忘记密码、个人中心、账号安全、工作台、系统管理、结果页、异常页、媒体库、订单、消息、组件中心，以及应用导航中的分析页、礼花效果、聊天和定价；会移除其余扩展业务、功能示例和模板页面。

```powershell
# 交互式清理，推荐使用
npm.cmd run clean:core
```

运行后先查看清理计划，再按提示确认。此命令在 Git 工作区存在未提交改动时会停止，避免误删已有开发内容。

如果项目是压缩包解压版本，或你明确确认要忽略当前 Git 改动，使用：

```powershell
npm.cmd run clean:core:no-git:dry
npm.cmd run clean:core:no-git
```

该命令会跳过 Git 脏检查，但仍然保留清理计划和交互确认。已预览并确认风险时，可使用以下一键命令：

```powershell
npm.cmd run clean:core:no-git:yes
```

## 4. 自定义保留模块

可选模块为：

- `extras`：扩展业务模块
- `examples`：功能示例页面
- `templates`：模板中心
- `account`：个人中心与账号安全
- `launcher-analytics`：应用导航中的分析页
- `launcher-templates`：应用导航中的聊天与定价页
- `components`、`component-navigation`：组件中心及入口，始终保留

例如，仅保留模板中心并清理其他可选模块：

```powershell
npm.cmd run clean:demo -- --keep=templates --yes
```

只预览，不执行删除：

```powershell
npm.cmd run clean:demo -- --keep=templates --dry-run
```

也可以按要删除的模块指定：

```powershell
npm.cmd run clean:demo -- --remove=examples,templates --yes
```

`--keep`、`--remove` 和 `--preset` 不能同时使用。

## 5. 快速清理命令

以下命令会跳过交互确认，只有在已经执行过预览并确认范围后使用：

```powershell
npm.cmd run clean:basic
```

压缩包或已有本地改动项目的快速清理：

```powershell
npm.cmd run clean:core:no-git:yes
```

## 6. 恢复被清理的内容

清理前建议保留 Git 提交或备份。若项目有对应 Git 历史，可以使用恢复命令：

```powershell
# 先预览恢复范围
npm.cmd run restore:core:dry

# 交互确认恢复
npm.cmd run restore:core

# 恢复组件中心
npm.cmd run restore:components
```

`restore:core` 只恢复核心版实际删除的 `extras`、`examples` 和 `templates` 模块；账户页与应用导航核心页本来就会保留，不会被恢复命令覆盖。

如果项目来自压缩包且没有可用 Git 历史，恢复命令可能无法找回已删除源码，只能从原始压缩包重新复制。

## 7. 清理后验证

清理完成后执行：

```powershell
npm.cmd run build
npm.cmd run lint
```

确认构建和代码检查通过后，再运行：

```powershell
npm.cmd run dev
```

## 8. 安全建议

1. 先执行 `dry` 预览，再执行真实清理。
2. 不确定时使用 `npm.cmd run clean:core`，不要直接使用 `clean:basic`。
3. `--yes` 和 `--allow-dirty` 会降低保护等级，只在确认清理范围后使用。
4. 清理会删除源码目录和更新路由/导航文件，操作前请备份项目或复制一份压缩包。

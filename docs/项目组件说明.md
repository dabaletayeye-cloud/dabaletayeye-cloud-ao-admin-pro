# ao-admin-pro 组件说明

本文档介绍项目中的布局组件、业务通用组件、基础 UI 组件和组件演示页。项目组件主要位于 `src/components/`，组件演示页位于 `src/pages/comp/`。

## 1. 应用外壳组件

| 组件 | 文件 | 用途 |
| --- | --- | --- |
| `AdminLayout` | `src/components/AdminLayout.tsx` | 管理后台主布局，组合侧栏、顶栏、面包屑、标签页、主题面板和内容区 |
| `Sidebar` | `src/components/Sidebar.tsx` | 垂直菜单、分组菜单、折叠状态和固定组件入口 |
| `HorizontalNav` | `src/components/HorizontalNav.tsx` | 横向菜单布局下的二级导航 |
| `Topbar` | `src/components/Topbar.tsx` | 顶部工具栏、主题入口、语言切换、通知和快捷入口 |
| `NavigationExtras` | `src/components/NavigationExtras.tsx` | 面包屑和多标签页等导航辅助能力 |
| `PageHeader` | `src/components/PageHeader.tsx` | 页面标题、说明和操作区的统一头部 |

`AdminLayout` 会根据主题状态切换垂直、水平、混合和双栏菜单，并负责内容区宽度、页面过渡和全局水印。

## 2. 主题与全局交互组件

| 组件 | 用途 |
| --- | --- |
| `ThemePanel` | 切换主题、亮暗模式、强调色、菜单样式、圆角、内容宽度和页面过渡 |
| `ThemeBackground` | 为页面提供主题背景和装饰层 |
| `NotificationPanel` | 通知列表、未读状态和通知操作 |
| `ChatAssistantPanel` | AO 助手聊天面板和消息交互 |
| `AppLauncher` | 应用快捷入口面板 |
| `LegacyTextLocalizer` | 兼容旧页面文本的运行时翻译 |
| `LocalizedText` | 对页面子树进行本地化文本处理 |

主题状态由 `src/hooks/useTheme.tsx` 管理，语言状态由 `src/hooks/useLocale.tsx` 管理，用户偏好会写入浏览器 `localStorage`。

## 3. 数据展示与业务通用组件

| 组件 | 适用场景 |
| --- | --- |
| `MetricCards`、`StatCards` | 指标卡、统计卡和趋势数据 |
| `Charts` | 图表组合和看板图形 |
| `ActivityFeed` | 最近活动、操作记录和动态流 |
| `TodoList` | 待办事项列表 |
| `NewUserList`、`UserOverview` | 新用户列表和用户概览 |
| `FilterToolbar` | 列表筛选、搜索和操作按钮区域 |
| `Topbar`、`NotificationPanel` | 全局操作和消息提醒 |

这些组件优先接受通过 props 传入的数据；当前项目中的数据多数来自 `src/data/` 模拟数据文件，接入后端时应将数据获取逻辑放在页面或业务 hook 中，不要让基础组件直接请求接口。

## 4. 基础 UI 组件库

`src/components/ui/` 是基于 Radix UI 和 Tailwind 样式封装的基础组件，页面应优先复用这些组件：

`accordion`、`alert`、`alert-dialog`、`aspect-ratio`、`avatar`、`badge`、`breadcrumb`、`button`、`calendar`、`card`、`carousel`、`chart`、`checkbox`、`collapsible`、`command`、`context-menu`、`dialog`、`drawer`、`dropdown-menu`、`form`、`hover-card`、`input`、`input-otp`、`label`、`menubar`、`navigation-menu`、`pagination`、`popover`、`progress`、`radio-group`、`resizable`、`scroll-area`、`select`、`separator`、`sheet`、`sidebar`、`skeleton`、`slider`、`sonner`、`switch`、`table`、`tabs`、`textarea`、`toggle`、`toggle-group`、`tooltip`。

基础组件的职责是提供一致的交互和样式，不应在其中写具体页面业务、路由跳转或接口请求。

## 6. 新增组件建议

1. 先判断组件是基础 UI、布局能力还是业务组件，再选择目录。
2. 基础 UI 放入 `src/components/ui/`；跨页面业务组件放入 `src/components/`。
3. 页面专用组件可以和页面放在同一目录，避免全局组件目录膨胀。
4. 组件需要支持主题时，优先使用 CSS 变量，例如 `var(--primary)`、`var(--card)` 和 `var(--border)`。
5. 组件需要文本时，使用 `useLocale()` 或现有翻译工具，不要在多个页面重复硬编码同一组文案。
6. 新增演示组件时，同时补充 `src/App.tsx` 路由和 `src/components/Sidebar.tsx` 菜单入口。

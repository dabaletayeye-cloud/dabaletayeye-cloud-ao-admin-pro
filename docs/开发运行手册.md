# 开发运行手册

## 1. 项目定位

`ao-admin-pro` 是一个基于 React、TypeScript 和 Vite 的中后台前端模板。当前版本以本地模拟数据和浏览器状态为主，不包含真实后端鉴权、数据库和生产接口层。

## 2. 环境准备

- Node.js 18 或更高版本，推荐使用当前 LTS。
- npm 9 或更高版本。
- Windows PowerShell 如果禁止执行 `npm.ps1`，使用 `npm.cmd`。

安装依赖：

```powershell
npm.cmd install
```

## 3. 本地开发

```powershell
npm.cmd run dev
```

默认地址为 `http://localhost:5174`。常用入口：

- `http://localhost:5174/login`
- `http://localhost:5174/register`
- `http://localhost:5174/`
- `http://localhost:5174/comp/overview`

## 4. 构建和检查

```powershell
# 生产构建
npm.cmd run build

# development 模式构建
npm.cmd run build:dev

# ESLint 检查
npm.cmd run lint

# 预览构建结果
npm.cmd run preview
```

构建产物位于 `dist/`，清理方式见 [清理组件命令说明](清理组件命令说明.md)。

## 5. 代码目录职责

```text
src/
├── components/       全局布局、业务通用组件和 UI 组件
├── data/             页面模拟数据、聊天数据和地图数据
├── hooks/            主题、语言和响应式 Hook
├── i18n/             i18next 初始化和语言资源
├── lib/              本地账户、提示消息和通用工具
├── pages/            业务页面、组件演示、模板和功能示例
├── types/            共享类型和主题类型
├── App.tsx           路由入口
└── main.tsx          React 挂载入口
```

## 6. 数据和状态约定

- 看板、表格、图表和聊天页面默认使用 `src/data/` 下的模拟数据。
- 主题配置使用 `admin-theme` 存储键。
- 语言由 i18next 管理，支持简体中文、繁体中文、英语、日语、韩语、法语和德语。
- 账户、待办、标签和部分页面偏好使用浏览器 `localStorage`。
- 接入后端时，应将请求封装在页面级服务或 hook 中，不要在基础 UI 组件内部直接请求接口。

清除本地演示状态：打开浏览器开发者工具，在 Application/存储中删除本站点的 localStorage，或执行：

```js
localStorage.clear();
location.reload();
```

## 7. 新页面开发建议

1. 先确定路由、页面分类和是否属于可清理演示模块。
2. 页面结构优先复用 `AdminLayout`、`PageHeader`、`FilterToolbar` 和 `src/components/ui/`。
3. 所有可见文本补充语言资源，并通过 `useLocale()` 获取。
4. 使用 CSS 变量适配主题，不直接依赖某一个主题的固定颜色。
5. 页面完成后依次执行 `npm.cmd run lint` 和 `npm.cmd run build`。

## 8. 常见问题

### PowerShell 无法运行 npm

使用 `npm.cmd` 替代 `npm`：

```powershell
npm.cmd run dev
```

### 端口 5174 被占用

关闭占用进程后重启，或检查 `vite.config.ts` 中的端口配置。项目启用了严格端口模式，不会自动切换到其他端口。

### 清理命令提示 Git 改动

先使用 `npm.cmd run clean:core:dry` 预览；压缩包或明确接受风险时使用 `npm.cmd run clean:core:no-git`。

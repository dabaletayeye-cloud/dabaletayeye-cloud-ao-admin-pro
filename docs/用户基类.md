# 用户基类

统一模型位于 `src/api/baseUser.ts`，使用抽象类 `BaseUser` 声明公共字段。`User`、`SystemUser`、`CurrentProfile` 都扩展它；当前账号缓存视图也复用这些字段。

```ts
import type { BaseUser } from '../api/baseUser';

export interface MemberUser extends BaseUser {
  accountType: 'member';
  points: number;
}
```

这是结构化数据契约：HTTP 和 Mock 仍返回普通 JSON 对象，不需要 `new`，也不使用 `instanceof`。用 `accountType` 标识账号类型、`clientId` 标识登录客户端，不要只用数值 ID 判断身份。

基类中可选字段可以在子类型里收紧为必填。写入请求单独使用字段白名单（例如 `SystemUserInput`），不要把整个用户对象作为更新请求发送。前端公共模型不包含密码摘要。

# 维护与发布检查清单

## 提交前

- [ ] 页面路由已在 `src/App.tsx` 注册。
- [ ] 侧栏或横向导航入口已同步更新。
- [ ] 复用现有 UI 组件，未重复实现基础控件。
- [ ] 新增文案已补充语言资源。
- [ ] 主题切换、亮暗模式和响应式布局已检查。
- [ ] 模拟数据没有混入真实密钥、密码或个人信息。

## 清理演示内容前

- [ ] 已运行 `npm.cmd run clean:core:dry` 或 `npm.cmd run clean:core:no-git:dry`。
- [ ] 已确认删除目录和更新的路由文件。
- [ ] 已复制项目或保留原始压缩包。
- [ ] 清理后仍需要的模块已在 `scripts/clean-demo.config.json` 中保留。

## 构建验证

```powershell
npm.cmd run lint
npm.cmd run build
```

构建通过后再运行：

```powershell
npm.cmd run preview
```

重点检查登录、工作台、系统管理、应用导航中的分析页/礼花效果/聊天/定价、结果页和异常页。

## 发布前检查

- [ ] `dist/` 中包含最新构建结果。
- [ ] 生产环境 API 地址和资源地址已确认。
- [ ] 未将 `.env`、密钥、测试账号或本地调试日志提交到仓库。
- [ ] 已验证刷新页面、直接访问深层路由和浏览器后退/前进。
- [ ] 已验证移动端宽度下侧栏、表格、弹窗和图表不溢出。
- [ ] 已记录本次清理或发布删除了哪些演示页面。

## 恢复策略

优先使用 `npm.cmd run restore:core:dry` 预览恢复范围，再执行 `npm.cmd run restore:core`。如果项目来自没有 Git 历史的压缩包，恢复只能从原始压缩包或备份中复制文件。
